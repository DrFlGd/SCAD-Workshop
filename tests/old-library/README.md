# A library with starter projects

A library as an app before 0.4.4 left it: two of the starter projects that came with
the app (`kind: "bundled"`), with their files, what the app read from them
(`derived/`), their README and their thumbnails, and nothing checked at its defaults.
The bench and the acceptance test start their libraries from a copy of it, to check
that such projects still open and render, are offered a check at their defaults, and
(for one that is on GitHub as the app had it) can come from GitHub instead (F-1).
